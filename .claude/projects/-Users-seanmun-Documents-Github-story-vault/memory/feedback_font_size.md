All text across the app must be 16px minimum. No exceptions.

**Why:** Target demographic is 55+ adults who may have vision impairments. The Bumper Test applies to readability too.

**How to apply:** Check all `text-xs` (12px) and `text-sm` (14px) usages — they need to be at least `text-base` (16px). This applies to labels, nav items, captions, tracking labels, pricing details, etc.
